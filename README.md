# Alpha ▲

موقع هبوط بسيط وأنيق، جاهز للتطوير.

## 🚀 التشغيل محليًا

افتح `index.html` في المتصفح مباشرة، أو شغّل خادمًا بسيطًا:

```bash
# باستخدام Python
python3 -m http.server 8000
```

ثم افتح: `http://localhost:8000`

## 📁 هيكل المشروع

```
alpha/
├── index.html        # الصفحة الرئيسية
├── css/
│   └── style.css     # التنسيقات
├── js/
│   └── main.js       # السكربتات
└── README.md
```

## ✨ المميزات

- تصميم عصري متجاوب (RTL)
- بدون أي مكتبات خارجية — HTML + CSS + JS خالص
- سرعة تحميل فورية

## 📝 التطوير

عدّل الملفات كما تشاء، ثم ادفع التغييرات:

```bash
git add .
git commit -m "وصف التعديل"
git push origin main
```

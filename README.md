# Alpha — نموذج ذكاء اصطناعي عربي صغير

هذا المستودع يوفّر **Qwen3-1.7B** — نموذج لغوي صغير الحجم (1.7 مليار معامل) يدعم اللغة العربية بثماني لهجات، مع سكربتات جاهزة لتحميله وتشغيله على أي جهاز.

## 🧠 عن النموذج

| الخاصية | القيمة |
|---|---|
| النموذج | **Qwen3-1.7B** (علي بابا) |
| الحجم بعد الضغط | ~1.1 جيجابايت (GGUF Q4_K_M) |
| اللغات | 119 لغة ولهجة (العربية بثماني لهجات: فصحى، مغربي، مصري، شامي، نجدي، عراقي، تونسي، تعزي-عدني) |
| الرخصة | Apache 2.0 (مجاني، تجاري، قابل للتعديل) |
| الذاكرة المطلوبة | 4-6 جيجابايت RAM |
| التخصص | محادثة عربية، فهم اللهجات المغاربية |

## 🚀 التشغيل السريع

```bash
# 1) تحميل النموذج (مرة واحدة فقط)
bash scripts/download-model.sh

# 2) تنصيب محرك التشغيل llama.cpp (إن لم يكن مثبتًا)
bash scripts/setup-llamacpp.sh

# 3) تشغيل الخادم
bash scripts/run-server.sh
# ثم افتح المتصفح على: http://localhost:8080

# أو جرّب محادثة نصية في الطرفية:
python3 scripts/chat.py
```

## 📡 استخدامه عبر API

الخادم يوفر واجهة متوافقة مع OpenAI:

```bash
curl http://localhost:8080/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{"messages": [{"role": "user", "content": "ما هي عاصمة الجزائر؟"}]}'
```

## ⚠️ ملاحظات مهمة

- **النموذج غير مخزّن في GitHub** (حجمه 1.1GB يتجاوز حد 100MB للملفات) — السكربتات هي التي تنزّله من Hugging Face
- النموذج يركز على **الفصحى** مع فهم محدود للهجات؛ الجودة تتأثر بحجمه الصغير (1.7B) — هو الأنسب للمحادثات القصيرة والمهام البسيطة
- للحصول على جودة أعلى: استخدم `Qwen3-4B` أو `Qwen3-8B` (تحتاج ذاكرة أكبر)
